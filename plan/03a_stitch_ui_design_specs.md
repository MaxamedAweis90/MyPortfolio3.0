# Phase 3A: Google Stitch Admin UI Specifications

## Design System & Tokens

- **Dark Mode (Default):**
  - Background: `#0A0D14` (`bg-mainBg`)
  - Surface/Cards: `#111622` / `#161C2C` (`bg-surface`)
  - Borders: `#222938` (`border-borderSubtle`)
  - Text Primary: `#F3F4F6`
  - Text Muted: `#94A3B8`
- **Brand Accents:**
  - Primary Accent: `#0B82EC` (Electric Royal Blue)
  - Secondary Accent: `#3B82F6` (Vibrant Sky Blue)
  - Teal Highlight: `#2DD4BF`
- **Typography:** `Outfit` / `Geist` clean modern developer aesthetic.
- **Component Style:** Modern Shadcn UI with subtle borders, rounded corners (`rounded-xl`), clean badges, and glow accents.
